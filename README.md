# Stefan Ianta

I build typed skill catalogues for AI agents — entries that declare what they
consume and what they produce, derived from recorded work rather than written by
hand, and graded by verifiers and certification graders I don't own.

- **[w3ai.org/ainations](https://w3ai.org/ainations)** — what the system does: the
  typed-edge model, two recorded episodes, and the numbers its own gates produced.
- **[iantalabs/ai-git-commands](https://github.com/iantalabs/ai-git-commands)** —
  the public end of it. A command catalogue with capability-typed install manifests
  (each host gets only the commands whose dependencies are actually present, every
  exclusion with its reason), plus `slog`, the cloud-lab session logger the derived
  catalogue is built from.
- **[github.com/iantalabs](https://github.com/iantalabs)** — the org, and where the
  current work lives.

Before this, 20+ years of technical delivery: AI/ML programs at Lockheed Martin,
General Dynamics and L3Harris; data lineage and migration at Scotiabank and CIBC.
[LinkedIn](https://www.linkedin.com/in/stefanianta/).

Most of what I am working on now is in private repos. The site is the honest version
of this page.
